apache vs nginx

Same traffic, two designs

Watch how each server handles connections and memory. Both sides get identical requests.

Quick comparison

nginxApache
Connection modelFew workers, each with an event loop that holds many connectionsProcess or thread per connection (prefork, worker), or the event MPM, which frees threads between requests
Static filesVery fast, uses sendfileGood
Dynamic contentPasses requests to PHP-FPM, uWSGI, Node or other appsCan embed the language (mod_php) or proxy to an app server
Per-directory configNo .htaccess. Central config, apply with a reload.htaccess files, checked per request when AllowOverride allows
ModulesMostly chosen at build time, dynamic modules supportedLoadable at runtime (mod_rewrite, mod_ssl, and others)
Memory with many connectionsLow and nearly flatGrows with the number of busy processes or threads
Typical roleFront door, reverse proxy, load balancer, static serverTraditional hosting with per-directory control
